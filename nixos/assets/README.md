# Demo VM assets

`desert-sunset.jpg` is the wallpaper the demo VM boots with, so a fresh VM shows
the shell generating its palette from an image rather than Hyprland's default
wallpaper.

Photo by Tim de Groot, released under CC0 (public domain dedication). Sourced
from Wikimedia Commons as `Stars@desertSunset(byTdeGroot).JPG`, cropped to 16:9
from the top edge and re-encoded to 3840x2160.
